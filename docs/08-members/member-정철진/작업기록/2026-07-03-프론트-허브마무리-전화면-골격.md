## 2. 발생한 문제와 해결 (중요)

### 2.1 흰 벽이 회색으로 렌더됨 (ACES 톤매핑)

- **증상**: 벽 재질을 `#ffffff`로 정확히 설정했는데 화면엔 회색으로 보였다.
  명도를 계속 올려도 체감 변화가 거의 없었다.
- **진단**: `preview_eval`로 캔버스 픽셀을 직접 읽었더니(`drawImage` →
  `getImageData`) 재질은 `#ffffff`인데 실제 렌더 픽셀은 `#aaaaaa`였다. 원인은
  두 가지였다 — ① R3F 기본 ACES Filmic 톤매핑이 밝은 색을 중간 회색으로 누름,
  ② ambientLight 강도(0.7)가 낮아 방향광을 정면으로 못 받는 벽면이 PBR 계산상
  어둡게 나옴.
- **해결**: `<Canvas flat>`으로 톤매핑을 끄고, ambient만 무식하게 올리면 명암
  대비가 사라져 평면적으로 보이므로 **반구광(hemisphereLight)+주광+보조광 3개**로
  나눴다. 방향광 못 받는 면도 밝기를 확보하면서 주광 반대쪽과 명암 차이는 유지된다.
- **교훈**: 3D에서 "색이 이상하다"는 육안 판단은 신뢰하지 말고 캔버스 픽셀을
  직접 읽어 재질값과 대조한다. R3F는 기본 톤매핑이 켜져 있다는 걸 항상 염두에 둔다.

### 2.2 배경 색 포인트 방향 전환 (사용자 피드백)

- 벽/바닥을 브랜드 컬러로 칠하려 했으나 navy는 조명에서 거의 검게, surface는
  캔버스 배경과 명도가 같아 안 바뀐 것처럼 보였다. 여러 배색을 시도한 끝에
  **색 포인트는 건물 내부가 아니라 Canvas 배경(건물 바깥 허공)에 주기로** 방향을
  틀었다. 최종적으로 벽/바닥은 뉴트럴(오프화이트/대리석), 배경은 검정으로 확정했다.

### 2.3 Kenney 바 엔드캡 회전 시 앵커 반전

- **증상**: `kitchenBarEnd`를 다른 바 모듈과 반대 방향으로 돌렸더니 위치가 어긋났다.
- **원인**: 회전이 반대(+90° vs -90°)면 모델 앵커 기준점도 반대로 뒤집혀
  x/z 오프셋 부호가 바뀐다.
- **해결**: 반전된 앵커 기준으로 좌표를 다시 실측해 bar3와 맞닿게 재계산했다.

### 2.4 @dnd-kit 하이드레이션 경고

- **증상**: 칸반 보드에서 `aria-describedby` 값이 SSR/CSR 사이 다르다는
  하이드레이션 경고가 떴다(`DndDescribedBy-0` vs `-2`).
- **원인**: @dnd-kit이 접근성용 id를 세션 카운터로 자동 생성하는데, HMR로 같은
  탭에서 반복 리마운트되며 카운터가 어긋난 것이었다(라이브러리 알려진 이슈,
  시각/기능엔 영향 없음).
- **해결**: `DndContext`에 고정 id를 줘봤으나 근본 원인은 라이브러리 쪽이라,
  서버를 콜드 스타트로 재시작하니 경고가 깨끗이 사라졌다. 실제 배포 빌드에선
  발생하지 않는 종류의 개발 중 경고로 판단했다.

### 2.5 숨은 진입점 404 버그 2개

- HubOverlay가 가리키던 `/[companyId]/dm`과 `/[companyId]/notifications` 경로에
  실제 페이지 파일이 없어 404였다(스켈레톤은 `dm/[roomId]`, `[projectId]/
  notifications`만 존재). S09 DM 목록 페이지와 회사 단위 S11 알림 페이지를 새로
  만들어 해결했다. 알림은 화면정의서가 "MVP는 GLOBAL scope만 허용"이라 회사 단위
  경로로 뒀다.

### 2.6 (도구 한계) 드래그앤드롭 자동 검증 불가

- `preview_eval`로 합성 `PointerEvent`(pointerdown/move/up)를 여러 방식으로
  쏴봤지만 @dnd-kit 포인터 센서가 반응하지 않았다. 합성 이벤트로 DnD 라이브러리를
  흉내내는 건 정식 e2e 도구에서도 별도 헬퍼가 필요한 흔한 한계다. 드래그 연결
  로직(같은 `changeStatus` 경로)·권한 검증은 select로 교차 확인했고, 실제 마우스
  드래그는 사용자가 육안으로 확인했다.

## 3. 이번에 확정한 구현 관례

- **mock + TODO 주석**: 백엔드 API가 전무해서 모든 화면이 로컬 state로 동작한다.
  실 연동 지점마다 `// TODO: POST /api/v1/...` 형태로 정확한 엔드포인트를 남겨
  Sprint 2 백엔드 완료 후 그 자리만 교체하면 되게 했다.
- **role 상수 하드코딩**: `/auth/me` 연동 전이라 `MOCK_ROLE = "C"` 같은 상수로
  역할별 분기를 흉내낸다. auth 가드가 없어 접근 제한은 시각적 표기로만 남겼다.
- **신규 의존성**: 칸반 DnD용으로 `@dnd-kit/core`·`@dnd-kit/utilities`만 추가했다
  (`@dnd-kit/sortable`은 컬럼 내 정렬이 필요 없어 설치 후 제거). 그래프 뷰·마크다운
  미리보기는 라이브러리 없이 SVG·최소 파서로 직접 구현해 의존성을 아꼈다.
- **뒤로가기 계층**: 허브 직속 화면→"허브로", 프로젝트 하위→"프로젝트 목록",
  2단계 상세→상위 목록. 텍스트/스타일을 `← 대상` 형식으로 통일했다.
