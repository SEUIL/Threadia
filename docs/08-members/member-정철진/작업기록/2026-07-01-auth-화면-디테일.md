## 1. 작업 개요

`feature/auth-screens` 브랜치에서 auth 4개 화면(login / signup / forgot-password / reset-password)의
레이아웃을 구현한 뒤, "하루에 화면 1~2개를 집중적으로 디테일하게" 기조로 연출을 4단계에 걸쳐 추가했다.

| 단계 | 작업 | 결과 |
|---|---|---|
| 1 | 비주얼 마감 | 로고 그라데이션 배지, 카드 상단 accent 라인, `AuthCard` 공통 컴포넌트 추출 |
| 2 | 진입 애니메이션 | 로고→카드 stagger fade-up, `prefers-reduced-motion` 대응 |
| 3 | 폼 마이크로 인터랙션 | 비밀번호 show/hide 토글, 강도 미터, focus 시 label 강조, loading 버튼 |
| 4 | Aurora 배경 | teal/violet/aqua 그라데이션 커튼(북극광 느낌) |
| + | 루트 리다이렉트 | `/` 접속 시 `/login` 으로 자동 이동 |

### 새로 만든 컴포넌트

- `components/auth/AuthCard.tsx` — 카드 컨테이너 + 상단 accent 라인(before pseudo)
- `components/ui/inputBase.ts` — 인풋 공통 클래스 상수(중복 제거)
- `components/ui/TextField.tsx` — label + input + focus 강조
- `components/ui/PasswordField.tsx` — show/hide 토글 + 강도 미터 옵션
- `components/ui/PasswordStrength.tsx` — 강도 바(약함/보통/강함)
- `components/ui/Button.tsx` — loading 스피너 내장

> 4개 화면에 복붙돼 있던 카드/인풋/버튼 마크업을 위 컴포넌트로 통일했다.
> Day 4 API 연동 시 `react-hook-form` 을 이 컴포넌트에 그대로 물리면 된다.

### 디자인 원칙 (유지)

- `style={{ }}` 인라인 스타일 금지 → 전부 Tailwind className.
- 색·radius·duration·그림자는 `globals.css` 의 `@theme` 토큰만 사용, hex/px 하드코딩 금지.
- 의존성 방향: 팔레트 원색(`--color-palette-*`) → 시멘틱 토큰(`--color-primary` 등) → Tailwind 클래스 → 컴포넌트.

## 2. 발생한 문제와 해결 (중요)

### 2.1 로그인 버튼이 흰색으로 렌더링됨

- **증상**: `bg-primary` 를 준 버튼이 teal 이 아니라 흰색/투명으로 나옴.
- **원인**: `globals.css` 하단의 전역 리셋 `button { background: none; }` 이 `@layer` **밖**에 있었다.
  Tailwind v4 는 유틸리티(`bg-primary`)를 `@layer utilities` 안에 생성하는데, **레이어 밖 CSS 는 cascade 상
  모든 레이어를 이긴다.** 그래서 `background: none` 이 `bg-primary` 를 덮어썼다.
- **해결**: base 리셋 전체를 `@layer base { }` 로 감쌌다. 그러면 utilities 레이어가 base 를 이겨서 정상 적용.
- **교훈**: Tailwind v4 에서 직접 쓰는 전역 리셋/기본 스타일은 반드시 `@layer base` 안에 둔다.

### 2.2 Aurora 배경색이 아예 안 나옴 (@theme 캐시)

- **증상**: `@theme` 에 `--color-aurora-1/2/3` 토큰을 추가하고 `bg-aurora-1` 을 썼는데 배경이 투명.
  컴파일된 CSS 에 `aurora` 문자열이 **한 글자도 없었다.**
- **원인**: `@theme` 에 **새 토큰을 추가**하거나 소스에 **처음 등장하는 유틸 클래스**(`bg-aurora-*`)를 쓰면
  Turbopack 의 `.next` 캐시가 재스캔을 하지 않아 반영되지 않는다. (같은 div 의 `blur-3xl`, `opacity-20` 이
  멀쩡히 보였던 건 그것들이 **기존에 이미 생성돼 있던 정적 유틸**이었기 때문.)
- **해결**: 서버 중지 → `.next` 삭제 → 재시작. 그제서야 `--color-aurora-*` 와 `.bg-aurora-*` 가 생성됐다.
- **교훈**: `@theme` 토큰 추가/신규 유틸 최초 사용 시엔 `.next` 를 지워야 한다.
  단, **기존 토큰 값 변경**이나 **이미 쓰던 유틸의 수치 조정**(opacity/크기 등)은 HMR 로 즉시 반영된다.

### 2.3 .next 삭제 중 서버가 죽음 (OneDrive 충돌)

- **증상**: dev 서버가 켜진 상태에서 `.next` 를 지웠더니 페이지가 `Internal Server Error`.
  로그에 `Compaction failed: Another write batch already active`,
  `build-manifest.json ENOENT`, `Cannot find module '[turbopack]_runtime.js'`.
- **원인**: 저장소가 `OneDrive\바탕 화면\...` 경로라 OneDrive 가 `.next` 를 실시간 동기화하며 파일 락을 건다.
  서버가 `.next` 에 쓰는 도중 삭제 + OneDrive 동기화가 겹쳐 빌드 산출물이 손상됐다.
- **해결**: **서버 중지 → `.next` 삭제 → 재시작** 순서를 반드시 지킨다. 이 순서로 하면 정상 복구.
- **교훈**: 이 환경에서 `.next` 는 절대 서버 실행 중에 지우지 않는다.

### 2.4 Aurora 가 렌더는 되는데 화면에 안 보임 (stacking)

- **증상**: blob 요소가 DOM 에 정상 존재(576px, opacity 0.7, 올바른 색)하는데 화면엔 안 보임.
  opacity/크기를 아무리 키워도 그대로였다.
- **원인**: blob 컨테이너에 `-z-10` 을 줬는데, wrapper 에 불투명한 `bg-background` 가 있어서
  **wrapper 배경색이 음수 z-index blob 을 덮어버렸다.** (진짜 원인은 opacity 가 아니라 z-index 였다.)
- **해결**: blob 레이어를 `z-0`(배경 '위')로 올리고, 콘텐츠(header/main/footer)를 `relative z-10` 로 감싸
  blob 위에 얹었다. 스택 순서 = wrapper bg → blob(z-0) → 콘텐츠(z-10).
- **교훈**: 배경 장식을 `-z` 로 밀면 부모 배경색에 가려질 수 있다. 배경 위·콘텐츠 아래에 두려면
  장식은 `z-0`, 콘텐츠는 `z-10` 로 명시적으로 쌓는다.

### 2.5 원 3개 → 오로라 커튼으로 재설계

- **증상**: `rounded-full` blob 3개를 코너에 배치했더니 "북극광"보다 "코너에 박힌 색 뭉치"처럼 보임.
- **해결**: 원 대신 **가로로 넓게 늘인 타원 그라데이션**(`rounded-[50%]` + `w-[160%]` + `blur-3xl`)을
  상·하단에 겹치고, 각 겹을 `from-aurora-1 via-aurora-3 to-aurora-2` 처럼 색이 흐르게 했다.
  반대 방향 그라데이션을 겹쳐 색이 자연스럽게 블렌딩되도록 했다.
- **최종 강도**: opacity 0.10~0.15 로 은은하게 조정(여러 번 다이얼 다운).

### 2.6 (참고) 프리뷰 도구 관측 한계

- `:focus` / `:focus-within` 스타일은 프리뷰 창이 백그라운드일 때 `getComputedStyle` 에 반영되지 않는다.
  (`matches(':focus-within')` 는 true 지만 계산 스타일은 미반영.) CSS 가 맞아도 관측이 안 되니,
  규칙 존재·매칭·specificity 를 분석해 검증했다. → **실제 브라우저(창 포커스)에서는 정상 작동.**
- 스크린샷 도구가 종종 30s timeout 으로 멈춘다(페이지 자체는 정상). 재시도하거나 eval 로 DOM 을 검증했다.

## 3. 검증 결과

- 4개 화면 렌더 정상, 콘솔/서버 에러 0.
- 비밀번호 토글: `password ↔ text` 전환 + `aria-label` 전환 확인.
- 강도 미터: `abc`=약함(1칸) / `abcd1234`=보통(3칸) / `Abcd1234!@`=강함(4칸, success 색) / 빈값=숨김.
- 루트 `/` 접속 → `/login` 자동 이동 확인.
