# 로컬 개발 환경 기동 가이드

> 개인 작업 환경(OneDrive 한글 경로) 기준 백엔드/프론트엔드/DB를 새 세션에서 다시 켤 때 쓰는 명령어 모음이다. 재부팅이나 세션 전환 시 프로세스가 살아있지 않으므로 매번 이 순서대로 기동한다.

---

## 1. Docker Desktop

세션 시작 시 Docker Desktop 데몬이 꺼져 있는 상태로 시작한다. `docker ps`가 파이프 오류를 내면 아래로 띄운다.

```powershell
Start-Process 'C:\Program Files\Docker\Docker\Docker Desktop.exe'
```

띄운 뒤 5~10초 정도 기다렸다가 `docker ps`로 확인한다.

---

## 2. MySQL 컨테이너 (`threadia-mysql84`)

컨테이너가 이미 생성돼 있고 멈춰만 있는 경우:

```powershell
docker start threadia-mysql84
```

컨테이너 자체가 없을 때(최초 생성):

```powershell
cd "C:\Users\cjfwl\OneDrive\바탕 화면\javaProject\Threadia"
docker compose --env-file .env -f compose.mysql.yml up -d mysql
```

`.env`에 `THREADIA_DB_PASSWORD`, `THREADIA_DB_ROOT_PASSWORD`가 설정돼 있어야 한다(`compose.mysql.yml` 참조, 포트는 `3307:3306`).

---

## 3. 백엔드 (Spring Boot)

```powershell
cd "C:\Users\cjfwl\OneDrive\바탕 화면\javaProject\Threadia\backend"
./gradlew bootRun
```

포트 8080에서 뜬다. 끌 때는 해당 터미널에서 `Ctrl+C`.

SMTP(Gmail 앱 비밀번호) credential 없이 순수 backend 확인만 할 때는 mail health 체크를 꺼서 actuator health가 `DOWN`으로 안 뜨게 한다.

```powershell
./gradlew bootRun --args='--management.health.mail.enabled=false'
```

## 5. 강제 종료가 필요할 때

`Ctrl+C`가 안 먹거나 터미널을 찾을 수 없을 때, 실제 백엔드 프로세스를 특정해서 끈다.

```powershell
# 8080 포트를 물고 있는 프로세스(PID) 확인
Get-NetTCPConnection -LocalPort 8080 -State Listen | Select-Object OwningProcess

# 해당 PID와 그 PID를 띄운 gradlew 런처(보통 java 프로세스 2~3개)를 함께 종료
Stop-Process -Id <PID들> -Confirm:$false
```

`org.gradle.launcher.daemon.bootstrap.GradleDaemon` 프로세스는 Gradle 빌드 캐시용 데몬이라 매번 안 꺼도 된다 — 다음 `./gradlew bootRun`이 더 빨리 뜨는 이점이 있다. 다만 데몬이 이상 동작(메모리 과다 점유, 캐시 꼬임 등)하는 것 같으면 아래로 정리한다.

```powershell
# backend 디렉터리에서 실행 — 현재 프로젝트가 쓰는 Gradle 데몬만 정리
cd "C:\Users\cjfwl\OneDrive\바탕 화면\javaProject\Threadia\backend"
./gradlew --stop

# 위 방법으로 안 죽으면 프로세스 목록에서 직접 종료
Get-Process | Where-Object { $_.ProcessName -eq 'java' } |
  Where-Object { (Get-CimInstance Win32_Process -Filter "ProcessId=$($_.Id)").CommandLine -match 'GradleDaemon' } |
  Stop-Process -Confirm:$false
```

**다시 켜기(재시작)**: Gradle 데몬은 별도의 "시작" 명령이 없다 — `./gradlew`로 아무 명령이나 실행하면 데몬이 없을 때 자동으로 새로 뜬다. `bootRun`을 바로 안 하고 데몬만 먼저 띄워두고 싶으면:

```powershell
cd "C:\Users\cjfwl\OneDrive\바탕 화면\javaProject\Threadia\backend"
./gradlew --status   # 데몬 목록/상태 확인 (없으면 이 명령 자체가 새 데몬을 하나 띄움)
```

정리해서 종료 → 재시작 흐름으로 보면:

```powershell
cd "C:\Users\cjfwl\OneDrive\바탕 화면\javaProject\Threadia\backend"
./gradlew --stop      # 종료
./gradlew --status    # 재시작(데몬 새로 기동)
```
