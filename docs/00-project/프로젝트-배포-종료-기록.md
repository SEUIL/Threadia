# 프로젝트 배포 종료 기록

## 종료 범위

Threadia application resource를 종료했다. 저장소에는 public portfolio에 필요한 application source와 종료 기록만 보존하며, retired deployment source와 runbook은 제거한다.

## 완료된 정리

- AWS의 application resource(EC2, EBS, Elastic IP, ECR, RDS 및 수동 snapshot, S3, SSM, SES, CloudFormation, 프로젝트 IAM 구성, Route 53 domain)를 decommissioned 상태로 정리했다.
- 프로젝트 범위의 VPC 구성을 정리했다. 계정 기본 VPC와 AWS 관리형 기본 KMS key는 프로젝트 범위 밖이므로 유지한다.
- public source에서 retired deployment workflow, script, CloudFormation source와 runbook을 제거했다. 현재 source workflow는 `backend-ci`, `frontend-ci`, `docs-site-ci`만 유지한다.

## 검증 결과

확인 시점에 Threadia 관련 활성 application EC2, volume, Elastic IP, RDS instance와 snapshot, ECR repository, S3 bucket, SSM parameter, SES identity, 프로젝트 IAM 구성, Route 53 hosted zone·domain, CloudFormation stack이 없음을 확인했다.

GitHub deployment 및 Actions metadata의 삭제는 source cleanup이 merge된 뒤 별도 작업으로 진행한다. 이 기록은 해당 GitHub metadata가 이미 삭제되었다고 주장하지 않는다.

## 비용 관찰

AWS Cost Explorer에서 정리 당일 서비스별 양수 비용이 없음을 확인했다. 다만 월간 합계에는 이미 발생한 비용이 포함될 수 있고 billing 반영에는 지연이 있으므로, 이 결과는 billing이 이미 0이라는 주장을 의미하지 않는다. 정리 후에도 billing 화면에서 비용 발생 여부를 계속 관찰해야 한다.

## 비과금 보존 예외

### Google OAuth client

Google OAuth client는 보존한다. publishing status는 production에서 testing으로 변경했으며, 이는 client 삭제가 아니다. 이후 필요하면 별도로 client를 삭제할 수 있다.

### Gmail SMTP App Password 및 local test configuration

Gmail SMTP App Password와 local test configuration은 local testing을 위해 의도적으로 보존한다. 이 항목은 배포 인프라 밖의 비과금 예외이며, 폐기되었다고 주장하지 않는다.

### AWS 계정 접근 예외

`AWSReservedSSO_ThreadiaProvisioner_*`는 account-access 용도로 의도적으로 유지한다. 이는 application resource 또는 application deployment 권한이 아니며, 이 기록에는 account ID나 policy detail을 남기지 않는다.

## 증거 기록 원칙

종료 증거에는 secret, credential 값, 개인 정보, 계정 정보, resource identifier, ARN, host IP, raw command를 기록하지 않는다.
