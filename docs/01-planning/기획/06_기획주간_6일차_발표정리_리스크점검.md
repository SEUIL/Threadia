# 기획주간 6일차 발표 정리와 리스크 점검 - 5일차 흡수됨

> [!warning]
> 기획주간이 6일에서 5일로 줄어들면서 이 문서의 내용은 [[05_기획주간_5일차_Sprint1_Backlog_검증기준]]로 흡수되었다.
> Notion에 공유할 때는 이 문서를 별도 회차로 올리지 말고, 5일차 문서만 사용한다.

## 현재 처리 방식

- 발표 목차 작성은 5일차 후반에 진행한다.
- 시연 시나리오 정리는 5일차 후반에 진행한다.
- 리스크 대응표와 Week 2 진입 조건 점검도 5일차에 함께 처리한다.
- 이 파일은 기존 6일 구조에서 어떤 내용이 있었는지 확인하기 위한 보관용 안내 문서로만 둔다.

## 5일차로 이동된 내용

| 기존 항목 | 이동 위치 |
|---|---|
| 1~5일차 산출물 점검 | 5일차 작업 묶음 4 |
| MVP freeze | 5일차 작업 묶음 4 |
| 발표 목차 작성 | 5일차 작업 묶음 4 |
| 시연 시나리오 작성 | 5일차 작업 묶음 4 |
| 리스크와 대응 정리 | 5일차 작업 묶음 4 |
| Week 2 진입 조건 확인 | 5일차 Week 2 진입 조건 |
| 발표 역할 분담 | 5일차 마무리 회의에서 확인 |

## 사용 기준

- 팀 공유용 문서 세트에는 1~5일차만 사용한다.
- 이 문서를 수정해서 새 6일차를 만들지 않는다.
- 발표/리스크/Week 2 준비 내용은 5일차 문서에서 관리한다.
