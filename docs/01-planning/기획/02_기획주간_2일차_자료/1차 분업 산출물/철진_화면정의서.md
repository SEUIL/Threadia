# 화면정의서

> Jira + Confluence + Slack 경량 애자일 협업 플랫폼  
> 기술 스택: React · Next.js · Three.js | Spring Boot | MySQL 8.4 | AWS EC2 / S3  
> 작성일: 2026.06

---

## 사용자 타입

| 코드 | 사용자 유형 | 설명 |
|------|------------|------|
| A | 일반 사용자 | 소속 프로젝트 내 업무 수행 |
| P | 프로젝트 관리자 | 특정 프로젝트의 PM. 일반 사용자 기능 포함 |
| C | 회사 관리자 | 특정 회사의 관리자. P·A 기능 포함 |
| F | 플랫폼 관리자 | 전체 플랫폼 관리자 |
| - | 비로그인 사용자 | 로그인 전 진입 상태 |

---

## 전체 화면 흐름

```
서비스 진입
  └── S01 로그인
        ├── S02 회원가입
        └── S03 3D 사무실 (메인 허브)
              ├── S04 프로젝트 목록
              │     ├── S05 칸반 보드
              │     │     └── S10 쓰레드
              │     ├── S06 백로그 / 스프린트
              │     ├── S07 문서·회의록 목록
              │     │     └── S08 문서 편집기
              │     └── S12 프로젝트 설정
              ├── S09 채팅 (DM)
              │     └── S10 쓰레드
              ├── S11 알림
              ├── S13 회사 관리
              │     └── S14 구성원·권한 관리
              └── S15 플랫폼 관리자 대시보드
```

## 화면 상세 정의

---

### S01 · 로그인

**접근 사용자:** 비로그인  
**화면 목적:** 서비스 최초 진입 화면. 이메일 + 비밀번호 인증으로 로그인.

**주요 구성 요소**

| 구성 요소 | 설명 |
|----------|------|
| 이메일 입력 필드 | 가입된 이메일 입력 |
| 비밀번호 입력 필드 | 비밀번호 입력 (마스킹) |
| 로그인 버튼 | 인증 요청 |
| 회원가입 링크 | S02로 이동 |

**이동 흐름**

| 액션 | 이동 대상 |
|------|----------|
| 로그인 버튼 클릭 (성공) | S03 3D 사무실 |
| 회원가입 링크 클릭 | S02 회원가입 |

|----------|------|

### S05 · 칸반 보드

**접근 사용자:** A / P / C  
**화면 목적:** 프로젝트 내 이슈를 칸반 형태로 관리. 카드 이동 및 쓰레드 접근 가능.

**주요 구성 요소**

| 구성 요소 | 설명 |
|----------|------|
| 프로젝트 사이드바 | 칸반·스프린트·문서·설정 메뉴 |
| 컬럼: To Do | 대기 중인 이슈 카드 목록 |
| 컬럼: In Progress | 진행 중인 이슈 카드 목록 |
| 컬럼: Done | 완료된 이슈 카드 목록 |
| 이슈 카드 | 이슈 제목, 담당자, 쓰레드 버튼 포함 |
| 쓰레드 버튼 | 카드 내 댓글/토론 진입 |
| + 이슈 추가 버튼 | 이슈 생성 모달 진입 |
| 드래그&드롭 | 카드를 컬럼 간 이동하여 상태 변경 |

**이동 흐름**

| 액션 | 이동 대상 |
|------|----------|
| + 이슈 추가 클릭 | 이슈 생성 모달 |
| 카드 클릭 | 이슈 상세 모달 |
| 카드 내 쓰레드 버튼 | S10 쓰레드 |
| 사이드바 - ⚙️ 설정 | S12 프로젝트 설정 |

### S08 · 문서 편집기

**접근 사용자:** A / P / C

| 저장 버튼 | 수동 저장 (자동저장 병행) |

**이동 흐름**

| 액션 | 이동 대상 |
|------|----------|
| 저장 버튼 클릭 | S07 문서 목록 (저장 완료) |
| 뒤로가기 | S07 문서 목록 |

### S10 · 쓰레드

**접근 사용자:** A / P / C

| 댓글 입력창 | 새 댓글 작성 및 전송 |

**이동 흐름**

| 액션 | 이동 대상 |
|------|----------|
| 상위 컨텍스트 배너 클릭 | S05 칸반 보드 (해당 카드) |
