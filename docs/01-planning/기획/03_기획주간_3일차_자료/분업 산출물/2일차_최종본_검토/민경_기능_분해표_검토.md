2. 프로젝트 대시보드가 없음

최종 기능분해표에 

HUB-01 | 공통 진입 | 3D 메인 허브 | S03
NAV-01 | 공통 진입 | 회사/프로젝트 선택 | S03, S04
PROJECT-01 | 프로젝트 목록 조회 | S04

이렇게 있음.

그리고 계층 다이어그램에도

프로젝트 홈 → 이슈 → 채팅/쓰레드 → 문서 → 알림 이라고 되어있음.

프로젝트 홈이라는 개념은 다이어그램에 존재하나 프로젝트 대시보드는 없음.

예를 들어

DASH-01 프로젝트 진행률 조회
DASH-02 최근 이슈 조회
DASH-03 최근 문서 조회
DASH-04 최근 활동 피드 조회

같은 기능 정의가 하나도 없음.

만약 프로젝트 홈 = 칸반 보드이면 대시기능 추가 안 해도 됨

프로젝트 홈
 ├ 진행률
 ├ 최근 이슈
 ├ 최근 문서
 ├ 최근 채팅
 └ Sprint 상태

이런 걸 보여주고 싶으면 기능분해표에 별도 추가해야 함.
