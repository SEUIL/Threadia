# Threadia 문서/협업 규칙 최신 변경사항

## 1. Root 협업 규칙 정리

- `AGENTS.md` 갱신
  - `CONTRIBUTING.md`, `docs/00-project/문서-작성-규칙.md`, `docs/AGENTS.md`, `docs/CLAUDE.md` 링크 추가
  - 문서별 역할 분리 명시
  - commit message 규칙을 multi-line 형식으로 변경

- `CLAUDE.md` 갱신
  - `AGENTS.md` 핵심 내용을 Claude Code용으로 복제
  - root 규칙, docs 규칙, commit message 규칙 동일하게 반영

- `CONTRIBUTING.md` 갱신
  - Git, commit, PR 기준 문서로 정리
  - commit message 형식을 아래처럼 변경

```text
type(scope): summary

1. 변경 내용
2. 변경 이유 또는 영향
```

## 2. AI/GitHub 표시 규칙 정리

- 기존 “AI 도구나 agent 이름을 GitHub collaborator, author, reviewer 등에 남기지 않는다” 류의 제한 문구 제거
- PR Template에서도 AI 사용 여부 섹션 제거
- 현재 기준은 “민감정보 금지”와 “사람이 이해하고 검토할 책임” 중심으로 정리

## 3. Docs 문서 작업 규칙 추가

- `docs/CLAUDE.md` 생성
