# 협업 하네스 최소 규칙 초안

## 목적

회의 전에 root의 `AGENTS.md`, `CLAUDE.md`, `CONTRIBUTING.md`를 보고 팀이 실제로 지킬 수 있는 최소 협업 규칙을 정리한다. 이 문서는 최종 규칙이 아니라 회의 검토용 초안이다.

## 초안 내용

| 문서 | 현재 역할 | 회의 전 확인할 내용 |
|---|---|---|
| `AGENTS.md` | 사람과 AI가 함께 따르는 repository 작업 규칙 | 범위가 너무 넓지 않은지, 실제 개발자가 읽고 지킬 수 있는지 확인 |
| `CLAUDE.md` | Claude Code 사용자가 `AGENTS.md`, `CONTRIBUTING.md`를 따르도록 연결 | 별도 규칙을 중복하지 않고 연결 문서 역할만 하는지 확인 |
| `CONTRIBUTING.md` | commit message, GitHub 표시 원칙, PR 전 기본 기준 | commit message 형식과 AI 표시 원칙이 팀 합의에 맞는지 확인 |

### 최소 규칙 후보

| 구분 | 후보 문장 |
|---|---|
| commit message | `type(scope): summary` 형식을 사용하고 summary는 한국어를 허용한다. |
| commit 단위 | 한 commit에는 한 가지 논리적 변경만 담는다. |
| 의미 없는 message | `WIP`, `수정`, `작업중`처럼 의미가 모호한 message는 PR merge 전에 정리한다. |
| secret 금지 | `.env`, API key, token, password, 개인정보는 commit하지 않는다. |
| AI GitHub 표시 | AI 도구나 agent 이름을 GitHub collaborator, author, co-author, reviewer, assignee로 남기지 않는다. |
| AI 사용 기록 | AI를 사용했다면 PR 설명의 AI 사용 여부와 범위에만 적는다. |

## 팀이 리뷰하고 결정할 것

| 결정 항목 | 선택지 | 회의 결과 |
|---|---|---|
| `AGENTS.md` 범위 | 현재 유지 / 더 줄임 / 항목 추가 |  |
| `CLAUDE.md` 역할 | 연결 문서로만 유지 / 세부 규칙 추가 |  |
| commit message 형식 | `type(scope): summary` 유지 / scope 선택화 / 다른 형식 |  |
| AI GitHub 표시 원칙 | 현재 문장 유지 / 더 명확히 수정 |  |
| 최종 반영 시점 | 4일차 마무리 / 5일차 시작 전 / 첫 PR 전 |  |
