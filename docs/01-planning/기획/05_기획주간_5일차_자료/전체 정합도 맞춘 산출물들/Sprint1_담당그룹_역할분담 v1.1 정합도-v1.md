# Sprint 1 Owner / Reviewer 배정안

> 기준
>
> * Owner는 `지원 담당` 안에서 지정한다.
> * Reviewer는 `지원 담당`에 포함되지 않은 사람 중에서 지정한다.
> * DB, 인증, OAuth, JWT, API처럼 위험도가 높은 작업은 가능한 한 황스일 님이 Reviewer로 들어가도록 배치한다.
> * 단, 황스일 님이 이미 지원 담당에 포함된 작업은 규칙상 Reviewer로 둘 수 없으므로 Owner 또는 지원 역할로 둔다.

---

> **Phase A 정합도 메모**: 이 파일은 공식 결정 반영 조정본이다. Sprint 1 구현 기준은 Auth only, Spring Boot/MySQL/Frontend skeleton, CI/PR baseline, Auth flows이며, Sprint 1 DB migration은 `users`, `oauth_accounts`, `password_reset_tokens`, `refresh_tokens`만 포함한다. 회사, 프로젝트, 이슈, 문서, 채팅, DM, 쓰레드, 알림, 프로필 수정, invitation 구현은 Sprint 1 범위에서 제외하고, 전체 MVP API/ERD는 후속 구현 sprint의 reference contract로 유지한다.

## 역할 배정 메모

| 항목          | 내용                                                                                  |
| ----------- | ----------------------------------------------------------------------------------- |
| 16번 작업      | 원래 지원 담당이 전체 인원이면 Reviewer를 지원 담당 밖에서 정할 수 없다. 그래서 실제 테스트 실행 인원 중심으로 지원 담당을 줄인 안이다. |
| 황스일 님 리뷰 배치 | 인증, DB, OAuth, API, E2E 테스트처럼 위험도 높은 작업 위주로 Reviewer에 배치했다.                         |
| 김태준 배치      | 인증 Entity, 비밀번호 재설정 API, E2E 테스트 쪽 Owner/Reviewer로 들어가도록 배치했다.                      |
| 여도현 배치      | 초기 Backend 세팅, DB 연결, 소셜 로그인 쪽 Owner로 배치했다.                                         |
| 김민경 배치      | 이메일 로그인 API, 버그 수정 쪽 Owner로 배치했다.                                                   |
